# Workspace Launcher — VS Code companion extension

Reads a Workspace Launcher config and creates/positions terminals inside
VS Code, running the configured dev commands (docs/build-shell.md, "VS
Code companion extension"). Not yet implemented — see `src/extension.ts`.

## Development

```sh
npm run watch -w apps/vscode-extension
```

Then press F5 in VS Code (with this folder open) to launch an Extension
Development Host.
